# Сеть Зоны / SnorkGram Pages — пакет ZONEbook 0.50 RC2 (F&B 0.47 + SnorkGram 0.46; нативная пересборка ожидается)

1. Создайте репозиторий для сайта и загрузите в него всё содержимое папки GitHubPages, включая snorkgram, snorkgram-server.json и .nojekyll. Файлы должны лежать в корне репозитория, а не в дополнительной папке.
2. Settings → Pages → Deploy from a branch → main → / (root) → Save.
3. После публикации скопируйте адрес сайта из Pages.
4. В игре откройте F&B → Инструменты → Адрес сети Зоны и вставьте полный HTTPS-адрес с папкой репозитория. Пустое поле возвращает локальную копию.

Адрес обычно выглядит как https://ИМЯ.github.io/РЕПОЗИТОРИЙ/. Можно указать свой домен. В конфигурацию входит только адрес сервера SnorkGram.

Одинаковые HTML работают в аддоне и на GitHub Pages. Фотографии, стили и поиск включены; внешние библиотеки и CDN не требуются. Переключение RU/EN ведёт на ту же страницу другого языка. Для проверки вне игры можно открыть index.html; рекомендуемый способ — локальный HTTP-сервер или GitHub Pages.

Портал, справочники и четыре сайта заказчиков открываются в обычном браузере. Кнопка в карточке открывает конкретный заказ только во встроенном локальном портале WebBridge, после пересборки безопасного EXE. Публичный HTTPS-сайт доступен для чтения и не получает право отправлять игровые команды. Условия и принятие заказа остаются в ноутбуке. Остальные 32 сервиса каталога работают в ноутбуке. При обновлении существующего сайта сохраните ваш snorkgram-server.json, если адрес сервера уже настроен. Страница SnorkGram открывает отдельно запущенный сервер из комплекта. Чтобы выдать всем посетителям адрес по умолчанию, внесите его в поле server_url файла snorkgram-server.json. Указывайте HTTPS-адрес корня своего сервера. При пустом поле игрок вводит адрес сам. Учётные записи и сообщения хранит сервер SnorkGram. GitHub Pages обслуживает статические страницы портала.

В интеграции 0.50 каноническая копия портала находится в 00_ZoneOS/gamedata/zonebook_network. Для проверки и зеркалирования используется QA/build_portal0451.py; полноценные редакционные генераторы 0.36.1 в этот релиз не включены. Статические стили и поведение находятся в assets/. Кнопки игровых сервисов передают только идентификатор разрешённого раздела или заказа.

Лицензии фотографий: images-sources.json и credits.html. Файлы фотографий сохранены без изменений; разметка использует кадрирование только при отображении. Сохраните авторство при публикации.

## Ветка F&B 0.47

Новые страницы расположены в `field/`, `science/`, `market/`, `radio/`, `tools/` и `en/`. Поиск на главной и каталог используют `assets/fb47-index.js`, сформированный из материалов обеих версий. Сайты не читают игровые сохранения, а локальные инструменты сохраняют черновики в профиле браузера.

**Для отображения новых страниц внутри встроенного WebBridge** требуется пересобрать его с ресурсами из `gamedata/zonebook_network`: поставленный в 0.50 RC2 EXE содержит старый портал 0.41. Публичная копия GitHub Pages работает самостоятельно после публикации, но не даёт полномочий игровых заказов.
